# カラーグレーディング（niho-photo#39）

シャドウ / 中間調 / ハイライト / 全体の明るさの帯ごとに色を乗せる補正。Lightroom のカラーの群の「カラーグレーディング」に当たる。エンジンはプリセット経由で色（色相・彩度）と、シャドウ・ハイライトの輝度を描いていた。0.19.0 で中間調・全体の輝度を足し、右パネルとスマホの編集の層から直せるようにした。旧形式の分割トーン（Split Toning）の画面は作らない（XMP の読み込みは従来どおり）。

## 保存形

`developSettings.colorGrading` は crate の `ColorGradingSettings` と同じ形で、Lightroom の XMP のカラーグレーディングも同じ値をそのまま持つ。形の版 `v` は変えない。

```json
{
  "colorGrading": {
    "shadow": { "hue": 220, "saturation": 40, "luminance": 0 },
    "highlight": { "hue": 35, "saturation": 45, "luminance": 0 },
    "midtone": { "hue": 0, "saturation": 0, "luminance": 15 },
    "blending": 100,
    "balance": 0
  }
}
```

- `hue` 0〜359（整数の角度。0 赤・60 黄・120 緑・180 シアン・240 青・300 マゼンタ。色の向きは ProPhoto の原色）、`saturation` 0〜100、`luminance` -100〜100、`blending` 0〜100、`balance` -100〜100。
- 無いゾーン・値は 0、無い `blending` は 100、無い `balance` は 0。
- 画面は直したゾーンだけを `{ hue, saturation, luminance }` で書き、ほかのゾーンと知らないキーは保つ。全部が既定（3 つの値が 0・`blending` 100・`balance` 0）になったらキーごと消す。

## 描画

色段 Q の最後（色ミキサーの後、出力変換の前）に linear ProPhoto で当てる。色（彩度）とシャドウ・ハイライトの輝度は Photo Bench の Lightroom 当てはめの移植のまま変えていない。

中間調・全体の輝度は NIHO の近似式で、**Lightroom の実測による校正は未実施**（参照の書き出しがまだ無い）。校正は `tools/calibrate` に新しい round を足し、定数を当てはめ直す。

- 形: 既存の帯と同じく `beta_weight(Y) × (lum / 50)` を R・G・B に同じだけ足す（正の値で明るく）。Beta の形 `p`・`q` は同じゾーンの彩度の当てはめ（`BAND_MIDTONE`・`BAND_GLOBAL`）を使うので、どちらも黒と白では 0 になる。全体は約 4Y(1−Y) の形で全域を同じ向きに動かし、黒と白の点は保ち、±100 でも単調。
- 大きさ: ±100 で帯の山の輝度を山の輝度の 27.26% だけ動かす（約 +0.35 EV）。既存のシャドウ（+100 で Y 0.2097 の位置を 0.0546 動かす。26.05%）とハイライト（Y 0.8085 で 0.2301。28.47%）の輝度の帯の、山での相対的な変化量の平均。絶対量では 2 つの帯の差が 4 倍あるが、相対量では 1 割以内でそろう。`a = 0.27257 × y* / 2 / (y*^p (1−y*)^q)`、`y* = p / (p + q)`（`color_ops.rs` の単体テストが再計算して照合する）。
- バランスはシャドウとハイライトの分け方だけを動かすので、中間調・全体の輝度には掛けない（ブレンドも、既存の輝度の帯と同じく掛けない）。
- 輝度が 0 の設定は従来と bit 単位で同じ画を描く（新しい項は最後に足し、0 なら飛ばす）。同梱の写真 3 枚 × 同梱プリセットと全項目のグレーディング 8 設定 × 2 サイズの描画の hash を 0.18.0 と比べ、48 件とも一致した。
- 中間調・全体の輝度は `needs_color_grading`、`is_neutral`、`has_active_color_edits` に数える（シャドウ・ハイライトの輝度と同じ扱い）。

合成の灰色の階調（sRGB 8bit、niho-10・niho-standard-1、補正なしとの差）での実測:

| 設定 | 5 | 40 | 96 | 128 | 160 | 192 | 224 | 245 | 255 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 中間調 +50 | 0 | +1 | +6 | +9 | +10 | +7 | +2 | 0 | 0 |
| 中間調 −50 | 0 | −1 | −6 | −10 | −11 | −7 | −2 | 0 | 0 |
| 全体 +50 | +1 | +6 | +10 | +12 | +12 | +11 | +7 | +2 | 0 |
| 全体 −50 | −1 | −7 | −12 | −14 | −13 | −11 | −7 | −2 | 0 |
| 中間調 +100 | 0 | +2 | +12 | +18 | +20 | +14 | +3 | 0 | 0 |
| 全体 +100 | +3 | +11 | +20 | +23 | +23 | +20 | +13 | +5 | 0 |

既存の当てはめでは、シャドウの輝度は + で暗く（+50 で 40 の灰色が −14）、ハイライトの輝度は + で明るい（+50 で 224 の灰色が +14）。シャドウの符号は Photo Bench の当てはめのままで、今回は変えていない。

シャドウに青（色相 220・彩度 60）、ハイライトに橙（35・60）を乗せると、灰色 45 は (5, 50, 66)、灰色 215 は (249, 206, 180) になる（青み・橙み。中間の 128 は (127, 128, 136)）。

## XMP・プリセット

- `ColorGradeMidtoneLum` / `ColorGradeGlobalLum` は、0 なら `exact`、0 以外は `approximate`（NIHO の近似式）。Photo Bench の判定（`photoBenchLevel`）は値を保持するだけの `unsupported` のまま。`unsupported` に入らないので、取り込みの「使えない項目」の知らせに出ない（画面の表からも「カラーグレーディングの輝度」を外した）。
- 変換器は `photo-bench-edit-settings-to-develop-v4`。0 以外の中間調・全体の輝度も変換する（v3 までは `colorGrading` ごと `legacySettings` に残り、そのプリセットのカラーグレーディング全体が描かれなかった）。
- プリセットの保存は、ほかのキーと同じく 0 も含めて 2 つの輝度を書く（当てた写真の輝度を戻す。Lightroom と同じ）。読み戻すと同じ値になる。
- 適用量（0〜150%）は 2 つの輝度にもほかの数値と同じく線形に掛かり、-100〜100 で止まる。
- コピー / 貼り付け・取り消しの履歴・プリセットの保存は `colorGrading` を素通しのキーとして扱う。

## 画面

- PC: カラーの群 → カラーミキサー → **カラーグレーディング** → ポイントカラー → 効果。節は既定で閉じ、開閉は端末に覚える。見出しの横の「初期化」は `colorGrading` だけを戻す。出す条件はカラーミキサーと同じ（段 2 の wasm が描いている写真）。
- 中身（PC とスマホ共通の 1 つの並び）: 帯の 4 択（シャドウ / 中間調 / ハイライト / 全体。既定でない値がある帯に点と「調整あり」の読み上げ）→ 色相環 → 色相・彩度・輝度のスライダー → ブレンド・バランス。Issue の「狭い幅は 3 つを縦に並べる」は、環を 3 つ縦に並べるとスマホの段の高さに収まらないため、狭い幅でもこの 4 択の切り替えで満たす。
- 色相環: 右が 0° で反時計回りに色相、中心からの距離が彩度。環の色はエンジンが乗せる色の向き（`grade_direction` を linear sRGB に写した、いちばん鮮やかな色）なので、HSL の同じ角度の色とはずれる。押した位置へ移してドラッグ（`drag` → 離して `commit`）、つまみをつかんだときは跳ばさない。ダブルクリックで彩度 0。つまみは Tab で focus し、←→ で色相 ±1°・↑↓ で彩度 ±1（Shift で 10）、Home / End / Delete / ⌫ で彩度 0。読み上げは「シャドウの色（色相 210°、彩度 40）」。数値の入力と読み上げの正は下のスライダー。
- スマホ: 編集の層の道具の帯に「カラーグレーディング」（カラーミキサーの後ろ）。段は高さ 17rem までで中を送り、環は少し小さくする。調整が入ると道具に点。

## 互換

- Mac のネイティブ書き出しは同梱の `niho-develop-render` の版（`apps/camera/develop-sidecars.lock.json`。main は 0.27.0、配布中の Mac アプリは 0.16.0）で描く。中間調・全体の輝度は形の版（`v`）を上げずに足したので、0.19.0 より前の renderer は黙って描かない。原寸へ渡すのは、renderer が `niho-develop-render capabilities` の `features` に `colorGradingLuminance` を挙げるときだけ（#131）。答えない古い renderer では原寸のカードを押せず、更新の案内を出す。
- 0.19.0 より前の wasm は中間調・全体の輝度を描かない。画面は `DEVELOP_ENGINE_CRATE_VERSION` で 0.19.0 の公開物を読む。
